# Installing the Unsigned Beta

This beta is not signed with an Apple Developer ID and has not been notarized by Apple. macOS will warn that Apple cannot check it for malicious software.

Only install it if you downloaded it from the official Floating Browser GitHub Release and trust the project. The source code is available in the same repository.

## Install

1. Drag **Floating Browser** to the **Applications** shortcut in this disk image.
2. Open **Floating Browser** from Applications. macOS will block the first attempt.
3. Open **System Settings > Privacy & Security**.
4. Scroll to Security and click **Open Anyway** for Floating Browser.
5. Confirm **Open** when macOS asks again.

The Open Anyway button is available for about one hour after the blocked launch attempt. After approval, the app opens normally.

Do not disable Gatekeeper and do not run Terminal commands that remove macOS security attributes.

## Requirements And Limitations

- macOS 14 or later.
- Apple silicon and Intel Macs are supported.
- Some streaming services block protected playback inside embedded WebKit browsers. Use **More > Open in Safari** when that happens.
- Disney+ may display Error 83 and require Safari.

Report ordinary bugs through GitHub Issues without including passwords, cookies, private URLs, payment details, or personal browsing information.
