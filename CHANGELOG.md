# Changelog

## 0.3.0 - Public Beta Candidate

- Added a system-safe Open Passwords shortcut and documented embedded WebKit's Password AutoFill limitation.
- Expanded the built-in launcher with Apple TV+, Peacock, Paramount+, and Tubi, and pointed Prime Video to Amazon's included-with-Prime catalog.
- Unified the glass navigation controls with the macOS title bar and removed the redundant Go button.
- Added visible status feedback for loading, errors, blocker changes, downloads, and WebKit recovery.
- Added close and restore controls to Mini mode.
- Split Home into Streaming and Saved sections with stable site colors.
- Expanded saved-site management with editing, removal, and reordering.
- Refreshed the browser chrome with compact symbol controls, a focused address field, and adaptive Liquid Glass on macOS 26 and later.
- Redesigned Home with a responsive, system-aware saved-site grid and clearer site identity.
- Simplified Mini mode to a single unobtrusive restore control over the video.
- Added a compact always-on-top Mini mode with a one-click Full restore control.
- Added saved site shortcuts, lightweight content blocking, downloads, and Safari fallback.
- Restored Prime Video's Safari-compatible browser identity.
- Added guarded recovery when a WebKit page process terminates repeatedly.
- Fixed address-field Return crashes and Mini-mode layout and preference persistence.
- Added universal Apple silicon and Intel release builds, notarized DMG packaging, privacy documentation, and MIT licensing.
- Adopted the stable `com.chrishansen.FloatingBrowser` bundle identifier for public builds, with one-time migration of preferences from earlier local builds.
