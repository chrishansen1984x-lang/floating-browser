# Changelog

## 0.3.0 - Public Beta Candidate

- Added a compact always-on-top Mini mode with a one-click Full restore control.
- Added saved site shortcuts, lightweight content blocking, downloads, and Safari fallback.
- Restored Prime Video's Safari-compatible browser identity.
- Added guarded recovery when a WebKit page process terminates repeatedly.
- Fixed address-field Return crashes and Mini-mode layout and preference persistence.
- Added universal Apple silicon and Intel release builds, notarized DMG packaging, privacy documentation, and MIT licensing.
- Adopted the stable `com.chrishansen.FloatingBrowser` bundle identifier for public builds, with one-time migration of preferences from earlier local builds.
