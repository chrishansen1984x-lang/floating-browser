# Security Policy

## Reporting A Vulnerability

Do not report security or privacy vulnerabilities in a public issue.

Use **Security > Report a vulnerability** in the GitHub repository to send a private report. Include the affected version, reproducible steps, expected impact, and any suggested mitigation. Do not include real account credentials, cookies, payment information, or unrelated personal data.

Private vulnerability reporting must be enabled in the repository settings before the first public release.

General playback failures and website compatibility bugs can use the public bug-report form as long as the report contains no private browsing or account information.
